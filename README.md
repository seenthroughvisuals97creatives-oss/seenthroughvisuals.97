# Seen Through Visuals — Editable Hub

## The important change

`index.html` does NOT contain the project images.

All images live separately inside:

`assets/images/`

This means you can replace an image without rebuilding the HTML.

## Updating an existing image

If a card says:

`image: "assets/images/project-03.png"`

replace `assets/images/project-03.png` with your new image while keeping the same filename.

The card will use the new visual automatically.

## Adding a new project

Open `index.html`, find:

`const PROJECTS = [`

Copy one complete project object and paste it before the closing `];`.

Change:

- `number`
- `name`
- `type`
- `image`
- `description`
- `story`
- `url`

## Website links

Put the PUBLIC website address in `url`.

For GitHub Pages, it will usually look like:

`https://USERNAME.github.io/REPOSITORY-NAME/`

The visitor is taken to that website in a new tab.

## Images

Recommended practice:

- PNG or JPG for normal visuals
- WebP is also fine
- Keep filenames simple
- Avoid spaces in filenames
- Use the same filename when replacing an image

The card uses `object-fit: cover`, so the image fills its frame without overflowing.

## Particles

The tiny star particles are generated by JavaScript at runtime.

They are not stored as files and are not saved in the HTML as individual particles.
They fade in, drift slightly, fade out, disappear, and are replaced by another small number of stars.
