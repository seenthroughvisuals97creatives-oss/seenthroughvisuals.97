IMAGE BEHAVIOUR:
All artwork frames use object-fit: contain. This means the complete uploaded image is preserved
inside its frame rather than being cropped. The surrounding area is intentionally dark so unusual
image aspect ratios still look intentional.

UPLOAD NOTE:
The image upload controls are for live browser preview/testing. They do not permanently upload
files to a public server. For permanent deployment, replace the files in assets/ or use a CMS/storage
backend if you want the owner to manage images from the website itself.

The site is intentionally one page and responsive on mobile.
